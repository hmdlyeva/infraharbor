# Code of Conduct

InfraHarbor contributors are expected to keep project spaces professional, respectful and focused on the work.

We welcome technical disagreement. Critique ideas, code and decisions rather than people. Harassment, threats, discriminatory abuse, deliberate intimidation, doxxing, or publishing another person's private information are not acceptable.

Maintainers may remove content or restrict participation when behavior repeatedly disrupts safe, productive collaboration. Reports about conduct should use the maintainer contact method documented by the repository owner rather than public escalation when privacy is needed.
